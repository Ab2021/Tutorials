## 1. Module purpose

This module teaches high-technology supply: configuration and BOM, component allocation, EMS, NPI ramp, network rollout, channel sell-through, aerospace AOG, obsolescence, and export control.

The survey file gives the module's narrative arc in one pass. This folder breaks that arc into
teaching units. Each topic file is a self-contained 2-4 hour block with mechanics, a worked
example, code or calculation, failure modes, assumptions, and exercises.

Read `_index.md` first, then the topics in order. Topics assume the prerequisites listed below,
not the whole program.

## 4. How the topics fit together

Each topic is written to stand alone, but they are ordered so that later topics can assume the
vocabulary of earlier ones. If you are short on time, the minimum path is the first topic plus
any topic that names your current decision problem.

```text
01 Configuration, BOM, and Life Cycle ->
02 Component Allocation under Shortage ->
03 EMS and Contract Manufacturing ->
04 NPI and Ramp ->
05 Telecom Network Rollout ->
06 Device Supply and Channel ->
07 Aerospace AOG and Parts Pools ->
08 Repair, Reverse, and Data Security ->
09 Obsolescence and Last-Time Buy ->
10 Export Control and Security
```

## 5. What this module does not cover

- It does not cover semiconductor device physics, chip design, or wafer fabrication.
- It does not cover aircraft engineering, airworthiness certification, or telecom radio planning.
- Hands-on lab execution: see the lab sections of the survey file.
- Legal advice: export control and airworthiness content requires professional review.
