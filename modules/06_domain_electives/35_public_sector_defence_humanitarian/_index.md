## 1. Module purpose

This module teaches supply under procedural and mission constraints: public procurement, defence availability, strategic stockpiles, humanitarian pipelines, last-mile distribution, and donor reporting.

The survey file gives the module's narrative arc in one pass. This folder breaks that arc into
teaching units. Each topic file is a self-contained 2-4 hour block with mechanics, a worked
example, code or calculation, failure modes, assumptions, and exercises.

Read `_index.md` first, then the topics in order. Topics assume the prerequisites listed below,
not the whole program.

## 4. How the topics fit together

Each topic is written to stand alone, but they are ordered so that later topics can assume the
vocabulary of earlier ones. If you are short on time, the minimum path is the first topic plus
any topic that names your current decision problem.

```text
01 Public Procurement and Frameworks ->
02 Whole-Life Cost and MEAT Evaluation ->
03 Defence Availability and Performance-Based Logistics ->
04 Strategic Stockpiles ->
05 Humanitarian Needs Assessment ->
06 Pipeline and Pre-Positioning ->
07 Last Mile in Fragile Settings ->
08 Cash versus In-Kind Assistance ->
09 Donor Reporting and Audit ->
10 Ethics, Protection, and Security
```

## 5. What this module does not cover

- It does not cover military strategy, tactics, or operational planning.
- It does not cover humanitarian programme design beyond logistics.
- Hands-on lab execution: see the lab sections of the survey file.
- Legal advice: procurement and export-control content requires professional review.
