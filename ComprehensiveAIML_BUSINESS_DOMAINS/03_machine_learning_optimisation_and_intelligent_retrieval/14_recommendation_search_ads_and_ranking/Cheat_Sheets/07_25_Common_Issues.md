## 4. 4. Core Formulas with Full Derivation
Validity before use: the calculation is a constructed teaching model with explicitly fixed inputs; it is not a performance promise.
Derivation: expected selected events equal selected count multiplied by a conditional rate.
```text
FORMULA [GEN-01]: E = n * p
WHERE: n is selected items [count]; p is an event rate [events/item]; E is expected events [events].
CONSTRAINT: p must refer to the same population, time window, and selection policy as n.
NUMERICAL EXAMPLE: n=60 items; p=0.18 events/item; E=60*0.18=10.8 events.
INTERPRETATION: fractional E is an expectation, not 0.8 of an observed event.
```
Boundary: at p=0, E=0; at p=1, E=n. A rate from a shifted population is not interchangeable.
**Takeaway:** Common issues: recommendation and retrieval is useful only under its declared decision, population, and evidence boundary.
