## 4. Core Formulas with Full Derivation
Validity before use: use a homogeneous illustrative cohort, stated costs, and a score calibrated for the chosen window; do not infer causality from a ranked list.
Derivation: expected actionable loss equals event probability times conditional loss, so ranking by a bounded expected value supports a capacity-constrained queue.
```text
FORMULA [09_Investigator_UX-01]: V_i = p_i * L_i - C_i
WHERE: V_i expected net value [currency/event]; p_i probability [0,1]; L_i prevented loss [currency/event]; C_i action cost [currency/event].
CONSTRAINT: p_i and L_i refer to the same horizon; action effect is an assumption needing validation.
NUMERICAL EXAMPLE: p_i=0.08, L_i=500 currency/event, C_i=12 currency/event; V_i=0.08*500-12=28 currency/event.
INTERPRETATION: under these illustrative inputs, a positive-value action is preferred only if capacity and guardrails allow it.
```
```text
FORMULA [09_Investigator_UX-02]: R_K = (sum of y_i for i in top K) / K
WHERE: R_K confirmed-positive rate [positives/review]; y_i mature binary outcome; K review capacity [reviews/window].
CONSTRAINT: unreviewed items lack labels, so R_K alone does not measure population precision.
NUMERICAL EXAMPLE: 9 mature positives among K=30 reviewed items gives R_30=9/30=0.30 positives/review.
INTERPRETATION: compare like windows and retain audits outside the queue.
```
