## 📚 Prerequisites & Preparation

### Theoretical Background

*   **Code generators are naive:** They often emit code like matching templates.
    *   `a = b + 0` -> `LOAD B`, `ADD 0`, `STORE A`. The `ADD 0` is useless.
*   **Window Size:** Typically 2 or 3 instructions. Larger windows are expensive to match.

### Practical Setup

*   **Input:** A list of "Assembly Instructions" (strings or objects).
*   **Output:** Leaner list.

---

## 📖 Theoretical Deep Dive

### 🔹 Part 1: Common Patterns

1.  **Null Sequences:**
    ```asm
    ADD R1, 0       ; Do nothing
    MUL R2, 1       ; Do nothing
    MOV R3, R3      ; Self-move (useless)
    ```

2.  **Combine Ops:**
    ```asm
    MOV R2, L1      ; Load address high
    ADD R2, 10      ; Add offset
    ; -> Optimizes to:
    LEA R2, [L1+10] ; x86 specific Load Effective Address
    ```

3.  **Redundant Load/Store:**
    ```asm
    MOV [Stack-4], R1   ; Spill R1
    MOV R1, [Stack-4]   ; Reload R1 immediately? Redundant!
    ```

4.  **Jumps over Jumps:**
    ```asm
         JZ Label1
         JMP Label2
    Label1:
         ...
    ; -> Optimizes to:
         JNZ Label2
    Label1:
    ```

### 🔹 Part 2: The Algorithm

1.  **Iterate:** `i` from 0 to N.
2.  **Window:** Look at `[i, i+1]`.
3.  **Match:** Does it fit a known pattern?
4.  **Replace/Delete:** Modify list.
5.  **Repeat:** Until no changes are made (Fixed Point).

## 💻 Implementation: Python Peephole Optimizer

```python
class Asm:
    def __init__(self, op, args):
        self.op = op
        self.args = args # list of strings
    
    def __repr__(self):
        return f"{self.op} {', '.join(self.args)}"

def optimize(instructions):
    changes = True
    while changes:
        changes = False
        new_insts = []
        skip_next = False
        
        for i in range(len(instructions)):
            if skip_next:
                skip_next = False
                continue
                
            curr = instructions[i]
            next_inst = instructions[i+1] if i+1 < len(instructions) else None
            
            # --- Pattern 1: Redundant Load after Store ---
            # STORE [addr], R1
            # LOAD R1, [addr] -> DELETE (R1 already has value)
            if next_inst and curr.op == "STORE" and next_inst.op == "LOAD":
                addr1, reg1 = curr.args[0], curr.args[1] # STORE [addr], src
                reg2, addr2 = next_inst.args[0], next_inst.args[1] # LOAD dest, [addr]
                
                if addr1 == addr2 and reg1 == reg2:
                    print(f"🔧 Optimized: Removed Redundant Load of {reg1}")
                    new_insts.append(curr) # Keep Store (memory might be needed)
                    skip_next = True
                    changes = True
                    continue

            # --- Pattern 2: Algebraic Identity (ADD 0, SUB 0) ---
            if curr.op in ["ADD", "SUB"] and curr.args[1] == "0":
                print(f"🔧 Optimized: Removed Identity {curr}")
                changes = True
                continue # Delete

            # --- Pattern 3: Self Move (MOV R, R) ---
            if curr.op == "MOV" and curr.args[0] == curr.args[1]:
                print(f"🔧 Optimized: Removed Self Move {curr}")
                changes = True
                continue

            # --- Pattern 4: Strength Reduction (MUL 2 -> SHL 1) ---
            if curr.op == "MUL" and curr.args[1] == "2":
                print(f"🔧 Optimized: Strength Reduction {curr} -> SHL")
                new_insts.append(Asm("SHL", [curr.args[0], "1"]))
                changes = True
                continue
                
            # No match
            new_insts.append(curr)
            
        instructions = new_insts
    
    return instructions

def main():
    code = [
        Asm("MOV", ["R1", "100"]),
        Asm("ADD", ["R1", "0"]),        # Junk
        Asm("STORE", ["[BP-4]", "R1"]),
        Asm("LOAD", ["R1", ["[BP-4]"]]), # Redundant
        Asm("MUL", ["R1", "2"]),        # Expensive
        Asm("MOV", ["R1", "R1"]),       # Junk
        Asm("JMP", ["L_END"])
    ]
    
    print("--- Original ---")
    for x in code: print(x)
    
    opt = optimize(code)
    
    print("\n--- Optimized ---")
    for x in opt: print(x)

if __name__ == "__main__":
    main()
```

## 🔬 Deep Dive: The Fixed Point

Notice the `while changes:` loop.
Some optimizations unlock others.
1.  `ADD R1, 0` is deleted.
2.  This might bring two `MOV`s adjacent to each other, revealing a redundant move that wasn't visible before.
3.  Optimizers run repeatedly until the code "stabilizes".

## 📝 Summary & Key Takeaways

1.  **Simple yet Powerful:** Peephole optimization is computationally cheap (linear pass) but reduces code size significantly (10-20%).
2.  **Target Specific:** It relies heavily on knowing the target ISA (e.g., x86 `INC` vs `ADD 1`).
3.  **Cleanup:** It acts as a garbage collector for inefficiencies left by earlier compiler phases.
