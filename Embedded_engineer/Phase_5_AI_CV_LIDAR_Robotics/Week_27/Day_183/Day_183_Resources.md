# Day 183: Contact-Implicit Control - External Resources

## 🔬 Practical Labs & GitHub Repositories
1.  **ToyotaResearchInstitute/idto**
    *   **Description:** Inverse Dynamics Trajectory Optimization for Contact-Implicit Model Predictive Control.
    *   **Link:** [https://github.com/ToyotaResearchInstitute/idto](https://github.com/ToyotaResearchInstitute/idto)
    *   **Relevance:** Directly addresses the contact-implicit optimization problem discussed in the lecture.

2.  **dojo-sim/ContactImplicitMPC.jl**
    *   **Description:** A fast contact-implicit model predictive control (MPC) implementation in Julia.
    *   **Link:** [https://github.com/dojo-sim/ContactImplicitMPC.jl](https://github.com/dojo-sim/ContactImplicitMPC.jl)
    *   **Relevance:** Excellent for understanding the mathematical formulation and implementation details, even if in Julia.

3.  **aykutonol/cito**
    *   **Description:** Contact-Implicit Trajectory Optimization.
    *   **Link:** [https://github.com/aykutonol/cito](https://github.com/aykutonol/cito)
    *   **Relevance:** C++ implementation useful for production-grade understanding.
