# Day 185: Optimal Control for Robotics - External Resources

## 🔬 Practical Labs & GitHub Repositories
1.  **AtsushiSakai/PythonRobotics**
    *   **Description:** A huge collection of robotics algorithms, including LQR, MPC, and iterative LQR.
    *   **Link:** [https://github.com/AtsushiSakai/PythonRobotics](https://github.com/AtsushiSakai/PythonRobotics)
    *   **Relevance:** The "Bible" of Python robotics algorithms; excellent for simple, readable implementations.

2.  **optimal_control_examples**
    *   **Description:** Python solutions to various optimal control problems using Direct Collocation and Shooting methods.
    *   **Link:** [https://github.com/andrespulido8/optimal_control_examples](https://github.com/andrespulido8/optimal_control_examples)
    *   **Relevance:** Focused specifically on the numerical methods discussed.

3.  **google-deepmind/mujoco**
    *   **Description:** MuJoCo Physics Engine.
    *   **Link:** [https://github.com/google-deepmind/mujoco](https://github.com/google-deepmind/mujoco)
    *   **Relevance:** Often the testbed for optimal control policies (LQR/iLQR).
