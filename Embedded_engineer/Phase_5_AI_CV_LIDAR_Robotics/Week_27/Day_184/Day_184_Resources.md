# Day 184: MPPI Control - External Resources

## 🔬 Practical Labs & GitHub Repositories
1.  **tud-amr/mppi-isaac**
    *   **Description:** Model Predictive Path Integral (MPPI) control implementation using Isaac Gym for massive parallel rollouts.
    *   **Link:** [https://github.com/tud-amr/mppi-isaac](https://github.com/tud-amr/mppi-isaac)
    *   **Relevance:** State-of-the-art implementation using GPU acceleration.

2.  **danielmohansahu/mppi-control-implementation**
    *   **Description:** A Clearpath Jackal MPPI implementation.
    *   **Link:** [https://github.com/danielmohansahu/mppi-control-implementation](https://github.com/danielmohansahu/mppi-control-implementation)
    *   **Relevance:** Good for seeing a standard CPU-based implementation for mobile robots.

3.  **Nav2 MPPI Controller**
    *   **Description:** The official MPPI controller in the ROS 2 Navigation Stack.
    *   **Link:** [https://github.com/ros-planning/navigation2](https://github.com/ros-planning/navigation2) (Look for `nav2_mppi_controller`)
    *   **Relevance:** Production-grade code used in industry.
