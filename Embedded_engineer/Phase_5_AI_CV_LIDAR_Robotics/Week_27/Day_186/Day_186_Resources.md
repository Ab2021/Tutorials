# Day 186: Learning-Based Control - External Resources

## 🔬 Practical Labs & GitHub Repositories
1.  **DLR-RM/stable-baselines3**
    *   **Description:** Reliable implementations of potential reinforcement learning algorithms (PPO, SAC, TD3) in PyTorch.
    *   **Link:** [https://github.com/DLR-RM/stable-baselines3](https://github.com/DLR-RM/stable-baselines3)
    *   **Relevance:** The industry standard for getting started with RL in robotics.

2.  **DLR-RM/rl-baselines3-zoo**
    *   **Description:** A training framework and collection of pre-trained agents for Stable Baselines3.
    *   **Link:** [https://github.com/DLR-RM/rl-baselines3-zoo](https://github.com/DLR-RM/rl-baselines3-zoo)
    *   **Relevance:** Provides tuned hyperparameters which are critical for RL success.

3.  **openai/gym** (now **Farama-Foundation/Gymnasium**)
    *   **Description:** The standard API for reinforcement learning environments.
    *   **Link:** [https://github.com/Farama-Foundation/Gymnasium](https://github.com/Farama-Foundation/Gymnasium)

## 📺 Video Tutorials & Lectures
1.  **Deep Reinforcement Learning for Walking Robots**
    *   **Source:** YouTube (MathWorks)
    *   **Link:** [Search Link](https://www.youtube.com/results?search_query=Deep+Reinforcement+Learning+for+Walking+Robots)
    *   **Description:** A practical guide using MATLAB/Simscape, but concepts apply 1:1 to Python/PyBullet.

2.  **Spinning Up in Deep RL (OpenAI)**
    *   **Source:** Website / Documentation
    *   **Link:** [https://spinningup.openai.com/](https://spinningup.openai.com/)
    *   **Description:** The best educational resource for understanding PPO and SAC.
