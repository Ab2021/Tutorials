# Day 187: Soft Robot Control - External Resources

## 🔬 Practical Labs & GitHub Repositories
1.  **sofa-framework/sofa**
    *   **Description:** Simulation Open Framework Architecture. The gold standard for soft body physics simulation.
    *   **Link:** [https://github.com/sofa-framework/sofa](https://github.com/sofa-framework/sofa)
    *   **Relevance:** Essential for simulating deformation in soft robotics.

2.  **jgilin/soft-robot-simulator**
    *   **Description:** PyBullet-based simulation for a cable-driven soft robot.
    *   **Link:** [https://github.com/jgilin/soft-robot-simulator](https://github.com/jgilin/soft-robot-simulator)
    *   **Relevance:** demonstrates how to model cable actuation in a rigid-body physics engine (approximation).

3.  **skriegman/evosoro**
    *   **Description:** Evolutionary Soft Robotics Simulator.
    *   **Link:** [https://github.com/skriegman/evosoro](https://github.com/skriegman/evosoro)
    *   **Relevance:** Focuses on the "Evolutionary" aspect of soft robot design.
