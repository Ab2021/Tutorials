# Day 205: Deployment & DevOps - External Resources

## 🔬 Practical Labs & GitHub Repositories
1.  **k3s-io/k3s**
    *   **Description:** Lightweight Kubernetes for Edge/IoT.
    *   **Link:** [https://github.com/k3s-io/k3s](https://github.com/k3s-io/k3s)
    *   **Relevance:** Managing a "fleet" of one or more robots.

2.  **Husarnet**
    *   **Description:** P2P VPN for ROS 2.
    *   **Link:** [https://husarnet.com/](https://husarnet.com/)
    *   **Relevance:** Connecting your robot to the cloud securely over 4G/5G.

3.  **ros-tooling/action-ros-ci**
    *   **Description:** The official GitHub Action for building ROS 2 packages.
    *   **Link:** [https://github.com/ros-tooling/action-ros-ci](https://github.com/ros-tooling/action-ros-ci)
    *   **Relevance:** Copy-paste this into your `.github/workflows`.
