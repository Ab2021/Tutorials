# Day 200: State Estimation & Telemetry - External Resources

## 🔬 Practical Labs & GitHub Repositories
1.  **cra-ros-pkg/robot_localization**
    *   **Description:** EKF/UKF node for fusing odometry, IMU, and GPS.
    *   **Link:** [https://github.com/cra-ros-pkg/robot_localization](https://github.com/cra-ros-pkg/robot_localization)
    *   **Relevance:** The standard "filter" node for ROS 2 state estimation.

2.  **cartographer-project/cartographer_ros**
    *   **Description:** Google's real-time SLAM (Simultaneous Localization and Mapping).
    *   **Link:** [https://github.com/cartographer-project/cartographer_ros](https://github.com/cartographer-project/cartographer_ros)
    *   **Relevance:** Generating the static map for optimization.

3.  **Foxglove Studio**
    *   **Description:** Modern visualization and debugging for robotics (better rviz).
    *   **Link:** [https://github.com/foxglove/studio](https://github.com/foxglove/studio)
    *   **Relevance:** Essential for visualizing "invisible" state covariance matrices.
