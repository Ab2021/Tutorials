# Day 201: Behavioral Intelligence - External Resources

## 🔬 Practical Labs & GitHub Repositories
1.  **BehaviorTree.CPP**
    *   **Description:** The C++ library for Behavior Trees (used by Nav2).
    *   **Link:** [https://github.com/BehaviorTree/BehaviorTree.CPP](https://github.com/BehaviorTree/BehaviorTree.CPP)
    *   **Relevance:** Industry standard for task switching.

2.  **splintered-reality/py_trees_ros**
    *   **Description:** Pythonic behavior trees for ROS 2.
    *   **Link:** [https://github.com/splintered-reality/py_trees_ros](https://github.com/splintered-reality/py_trees_ros)
    *   **Relevance:** Easier to prototype complex logic (Patrol, charge, interact).

3.  **ROS 2 Behavior Tree Example (Nav2)**
    *   **Link:** [https://navigation.ros.org/behavior_trees/index.html](https://navigation.ros.org/behavior_trees/index.html)
    *   **Relevance:** Good examples of XML-based tree definitions.
