# Day 190: Neuromorphic Computing for Robotics - External Resources

## 🔬 Practical Labs & GitHub Repositories
1.  **artiomn/awesome-neuromorphic**
    *   **Description:** The ultimate curated list of SNN frameworks, simulators, and datasets.
    *   **Link:** [https://github.com/artiomn/awesome-neuromorphic](https://github.com/artiomn/awesome-neuromorphic)
    *   **Relevance:** Your gateway to tools like BindsNET, Norse, and Intel Lava.

2.  **BindsNET/bindsnet**
    *   **Description:** Simulation of Spiking Neural Networks (SNNs) using PyTorch.
    *   **Link:** [https://github.com/BindsNET/bindsnet](https://github.com/BindsNET/bindsnet)
    *   **Relevance:** Allows simulating SNNs with a familiar PyTorch-like API, perfect for robotics integration.

3.  **Intel LAVA**
    *   **Description:** Software Framework for Neuromorphic Computing (supports Loihi).
    *   **Link:** [https://github.com/lava-nc/lava](https://github.com/lava-nc/lava)
    *   **Relevance:** Essential for interacting with Intel's actual neuromorphic chips.
