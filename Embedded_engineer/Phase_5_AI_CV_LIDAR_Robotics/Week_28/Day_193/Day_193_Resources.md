# Day 193: Soft Actuators & Materials - External Resources

## 🔬 Practical Labs & GitHub Repositories
1.  **Soft Pneumatic Actuator Design (Differentiable Simulation)**
    *   **Description:** Automated design of pneumatic actuators using gradient-based optimization.
    *   **Link:** [Search GitHub](https://github.com/search?q=soft+pneumatic+actuator)
    *   **Relevance:** Moving from "guesswork" design to algorithmic design.

2.  **Open-source Soft Robotic Gripper**
    *   **Description:** Files and code for a printable soft gripper.
    *   **Link:** [Search GitHub](https://github.com/search?q=soft+robotic+gripper)
    *   **Relevance:** A classic "Hello World" project for soft actuation.
