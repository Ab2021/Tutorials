## 🏗️ Final Project: "Nebula Platform"

### Scenario
**Goal:** A Data Scientist wants to deploy a "Fraud Detector".
**Constraints:**
1.  Must be billed to `CostCenter: Risk`.
2.  Must not use `root` user.
3.  Must access S3 `fraud-data` securely.

### Step 1: The Golden Template (Backstage)

#### 📁 `project/templates/ml-service.yaml`
```yaml
# ... Scaffolder Template ...
steps:
  - id: create-repo
    action: publish:github
    input:
      repoUrl: github.com?repo=${{ parameters.name }}
      # Defaults:
      # - Dockerfile (Non-root)
      # - Helm Chart (With Vault Annotations)
      # - Catalog Info (With tags)
```

### Step 2: The Guardrails (Kyverno)

Block deployments that drift from the template.

#### 📁 `project/policy/require-costcenter.yaml`
```yaml
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: require-cost-center
spec:
  validationFailureAction: enforce
  rules:
  - name: check-label
    match:
      any:
      - resources:
          kinds:
          - Pod
    validate:
      message: "You must specify a CostCenter."
      pattern:
        metadata:
          labels:
            CostCenter: "?*"
```

### Step 3: The Secret Store (Vault)

Configure the S3 Role.

```bash
vault write aws/roles/fraud-reader \
    credential_type=iam_user \
    policy_document='{"Version":"2012-10-17","Statement":[{"Effect":"Allow","Action":"s3:Get*","Resource":"arn:aws:s3:::fraud-data/*"}]}'
```

### Step 4: The Deployment (The "Fraud Detector")

This specific manifest is generated by Backstage, but let's look at the output.

#### 📁 `project/apps/fraud-detector/deploy.yaml`
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: fraud-detector
  labels:
    CostCenter: Risk # Satisfies Kyverno
spec:
  template:
    metadata:
      annotations:
        vault.hashicorp.com/agent-inject: "true"
        vault.hashicorp.com/role: "fraud-reader" # Satisfies Vault
    spec:
      serviceAccountName: fraud-sa
      containers:
      - name: app
        image: my-registry/fraud:v1
        securityContext:
          runAsUser: 1000 # Satisfies Non-Root Policy
```
